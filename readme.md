Projeto CSS Grid - Harry Potter

Sobre

Este projeto foi criado para praticar HTML e CSS Grid. A página possui o tema Harry Potter e apresenta um layout com cabeçalho, menu, galeria de personagens e rodapé.

Tecnologias utilizadas

* HTML5
* CSS3
* CSS Grid

Funcionalidades

* Layout organizado com CSS Grid.
* Galeria de personagens em formato de cards.
* Página responsiva para diferentes tamanhos de tela.

Como executar

1. Baixe os arquivos do projeto.
2. Abra o arquivo index.html em um navegador.

Autor

Projeto desenvolvido para fins de estudo e prática de CSS Grid.
